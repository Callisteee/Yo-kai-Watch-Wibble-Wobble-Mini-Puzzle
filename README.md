# Youtube Game - Yo-kai Watch Wibble Wobble Mini Puzzle
An extraction of all the Yo-kai Watch Wibble Wobble Mini Puzzle Youtube Game

This project is an extraction and recreation of the Yo-kai Watch Wibble Wobble Mini Puzzle Youtube game which was developed and published by Level-5.

**The game runs locally in your web browser.**

Python is required to launch the local server with the provided launcher.

- On Windows:
```text
start_game.bat
```

- On Linux/macOS:
```bash
'./start_game.sh'
```

You can also launch it manually with:
```bash
'python start_game.py'
```

No Internet connection is required to play once all resources are available locally.
